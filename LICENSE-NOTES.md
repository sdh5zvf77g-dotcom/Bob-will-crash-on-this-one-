# Model and data licensing notes

This repository does not bundle any model weights. Before downloading or training a model, read and accept the current licence/terms for that exact checkpoint. The `meta-llama/Llama-3.2-1B-Instruct` model is subject to Meta's Llama terms and may require authenticated access. Do not assume that model, adapter, or generated weights can be redistributed freely. Check the terms that apply to your intended use and jurisdiction.

Only use chat data you have permission to train on. Exported Bob memory may include sensitive personal data, API keys, document names or third-party information. Review and redact manually. Automated redaction is not complete.
